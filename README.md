# TUENCARGO
TUENCARGO es una página web la cual actúa como un intermediario en el proceso de compra en línea la cual cuenta con el propósito de facilitar y simplificar este, otorgando funcionalidades que van desde la optimización de precios de envió, hasta la comparación de costos entre diferentes paginas para un producto que el usuario este buscando.

TUENCARGO busca darle al comprador no solo control sobre el presupuesto que decide usar para un producto sino también una mejor experiencia a la hora de hacer compras en el internet
